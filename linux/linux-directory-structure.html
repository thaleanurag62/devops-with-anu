Linux Directory Structure Explained

Complete Beginner's Guide | DevOps with Anu

Introduction

Understanding the Linux directory structure is one of the first things every Linux beginner should learn. Unlike Windows, where drives such as C: and D: are commonly used, Linux uses a single hierarchical filesystem that starts from the root directory represented by /.

Every file, directory, device, configuration file, application, and system resource is organized somewhere under this root directory. Once you understand what the major directories are used for, navigating Linux servers and troubleshooting problems becomes much easier.

This guide explains the most important Linux directories in simple language and provides practical examples that beginners can use while learning Linux, DevOps, Cloud Computing, and System Administration.

What is the Linux Filesystem?

The Linux filesystem is a hierarchical structure used to organize files and directories. At the top of this hierarchy is the root directory, represented by a single forward slash: 

/

All other directories are located below the root directory. You can think of the root directory as the starting point of the entire Linux filesystem.

A simplified Linux directory structure looks like this: 

/
├── bin
├── boot
├── dev
├── etc
├── home
├── lib
├── media
├── mnt
├── opt
├── proc
├── root
├── run
├── sbin
├── srv
├── sys
├── tmp
├── usr
└── var

The exact contents can vary between Linux distributions, but these directories generally follow the Linux filesystem hierarchy conventions.

1. / — Root Directory

The / directory is the top-level directory of a Linux filesystem. Every other directory and file is located somewhere underneath it.

To view the contents of the root directory, use: 

ls /

You may see directories such as /home, /etc, /usr, /var, and /tmp.

Remember:

The root directory / is different from the /root directory. The first is the top of the filesystem hierarchy, while /root is the home directory of the root user.

2. /bin — Essential User Commands

The /bin directory traditionally contains essential commands required for basic system operation and for users to perform common tasks.

Examples of commands commonly associated with this area include: 

ls
cp
mv
cat
mkdir
rm

On many modern Linux distributions, /bin may be linked to /usr/bin as part of a filesystem layout known as merged-usr.

You can inspect the directory with: 

ls /bin

3. /boot — Boot Files

The /boot directory contains files required during the Linux boot process. These files help the system start the operating system when the computer is powered on.

You can inspect it using: 

ls /boot

Depending on the Linux distribution, you may find the Linux kernel, bootloader-related files, and initial RAM filesystem images here.

Warning: Do not randomly delete or modify files inside /boot. Incorrect changes can prevent a Linux system from booting.

4. /dev — Device Files

The /dev directory contains special files that represent devices connected to or recognized by the Linux system.

Linux treats many hardware devices as files, allowing programs to interact with them through standard filesystem interfaces.

For example: 

ls /dev

You may see entries representing disks, terminals, USB devices, and other hardware.

Some familiar examples include: 

/dev/sda
/dev/null
/dev/tty

5. /etc — Configuration Files

The /etc directory contains system-wide configuration files. These files control how many services and applications behave on a Linux system.

For example, you can view the contents using: 

ls /etc

Some commonly known configuration files include: 

/etc/hosts
/etc/hostname
/etc/passwd
/etc/fstab

System administrators frequently work with files in /etc when configuring servers and services.

Important: Be careful when modifying configuration files in /etc. An incorrect configuration can affect system services.

6. /home — User Home Directories

The /home directory contains the personal directories of normal users. Each user generally has a separate directory where their personal files and settings are stored.

For example:

/home/anurag
/home/user1
/home/user2

If your username is anurag, your personal files might be stored inside: 

/home/anurag

You can go to your home directory using: 

cd ~

The shortcut ~ represents the current user's home directory.

7. /lib — Essential Libraries

The /lib directory traditionally contains essential shared libraries and kernel modules required by programs and the Linux system.

Libraries provide reusable code that applications and system programs can use. This helps software work without every program having to contain all the required code itself.

You can inspect the directory with:

ls /lib

On many modern distributions using a merged-usr filesystem layout, /lib may be linked to a directory under /usr.

8. /media — Removable Media

The /media directory is commonly used as a mount point for removable storage devices such as USB drives, CDs, and DVDs.

For example, a USB device might be automatically mounted somewhere under: 

/media/username/USB

You can check mounted media using: 

ls /media

9. /mnt — Temporary Mount Point

The /mnt directory is commonly used as a temporary mount point for filesystems or storage devices.

For example, an administrator might mount a filesystem at: 

/mnt/data

The exact way storage is mounted depends on the system configuration and the administrator's requirements.

10. /opt — Optional Software

The /opt directory is intended for optional or additional software packages that are installed outside the standard system software layout.

For example, an administrator or software vendor may install an application under: 

/opt/myapplication

This can make it easier to keep certain third-party applications separated from the main operating system files.

Why Are These Directories Important?

Knowing the purpose of common Linux directories makes it much easier to navigate a Linux server and troubleshoot problems. For example, if you need to modify a system configuration, you will often look in /etc. If you need to find a user's personal files, you will normally look under /home.

Directory Main Purpose
/ Root of the entire filesystem
/bin Essential user commands
/boot Files required during system boot
/dev Device files
/etc System configuration files
/home Personal directories of normal users
/lib Essential libraries and modules
/media Mount points for removable media
/mnt Temporary filesystem mount point
/opt Optional or additional software

11. /proc — Process Information

The /proc directory is a virtual filesystem that provides information about running processes and the Linux kernel. Unlike normal files, much of the information in /proc is generated dynamically by the kernel.

You can view its contents with:

ls /proc

For example, directories containing numbers usually represent running processes. You can also view information about the CPU with: 

cat /proc/cpuinfo

The /proc filesystem is particularly useful for system monitoring and troubleshooting.

12. /root — Root User's Home Directory

The /root directory is the home directory of the root user, which is the administrative user on a Linux system.

It is different from the / root directory. The slash / represents the top of the filesystem, while /root belongs specifically to the root user's home directory.

You can access it when you have the required privileges:

sudo ls /root
Remember: Avoid using the root account for everyday work. Administrative commands should be used carefully because they can modify critical parts of the operating system.

13. /run — Runtime Data

The /run directory stores temporary runtime information created by the system and running services. This information is generally created during system startup.

You can inspect it with: 

ls /run

The exact files and directories inside /run depend on the Linux distribution and the services currently running.

14. /sbin — System Administration Commands

The /sbin directory traditionally contains important system administration commands. These commands are primarily used for managing and maintaining the operating system.

Examples can include commands related to networking, filesystem management, and system administration.

You can inspect it with:

ls /sbin

On modern Linux distributions, /sbin may also be part of a merged-usr layout and point to /usr/sbin.

15. /srv — Service Data

The /srv directory is intended for data served by system services. The name "srv" comes from the word "service".

For example, a server administrator may organize data for a web or file service under this directory. 

/srv
└── website

Its actual use depends on how the server is configured.

16. /sys — Kernel and Device Information

The /sys directory is another virtual filesystem provided by the Linux kernel. It exposes information about devices, drivers, and other parts of the system.

You can inspect it using:

ls /sys

The information in /sys is useful for system administrators and advanced users who need to inspect hardware and kernel-related information.

17. /tmp — Temporary Files

The /tmp directory is used by applications and users to store temporary files.

For example:

touch /tmp/test.txt

Temporary files may be removed automatically depending on the Linux distribution and its configuration.

Important: Do not use /tmp for important permanent data. Temporary files are not intended to be long-term storage.

18. /usr — User Programs and Data

The /usr directory contains a large amount of software, libraries, documentation, and other read-only user-space data used by the operating system.

Some important directories inside /usr include: 

/usr/bin
/usr/sbin
/usr/lib
/usr/share
/usr/local

For example, many applications and commands installed on a Linux system can be found under /usr/bin. 

ls /usr/bin

19. /var — Variable Data

The /var directory contains data that is expected to change while the system is running. This includes logs, caches, queues, and other application-generated data.

Some important locations include: 

/var/log
/var/cache
/var/tmp

The /var/log directory is especially important for system administration because it contains many system and application logs.

You can view available log files with:

ls /var/log

Practical Commands to Explore the Linux Filesystem

Now that you understand the major directories, you can explore them directly from a Linux terminal. 

pwd
ls /
ls /etc
ls /home
ls /var/log
cd /tmp
pwd

These simple commands are a good way to become familiar with the Linux filesystem. Always be careful when modifying system directories, especially when using administrative privileges.

Common Beginner Mistakes

  • Confusing / with /root.
  • Deleting important files from system directories.
  • Changing configuration files without understanding them.
  • Using sudo for commands that do not require administrative privileges.
  • Assuming Linux directories work exactly like Windows folders.

Frequently Asked Questions

What is the root directory in Linux?

The root directory is represented by /. It is the highest level of the Linux filesystem hierarchy, and all other directories exist underneath it.

What is the difference between / and /root?

The / directory is the top of the entire filesystem. The /root directory is the home directory of the root user.

Where are Linux configuration files stored?

Most system-wide configuration files are stored in the /etc directory.

Where are normal users' files stored?

Normal users generally have their personal directories under /home. For example, a user named Anu might have a home directory such as /home/anu.

Where are Linux log files stored?

Many Linux logs are stored under /var/log. The exact log files available depend on the distribution and installed services.

What is the /tmp directory used for?

/tmp is used for temporary files created by applications and users. Its contents may be cleaned automatically by the system.

Why is understanding the Linux directory structure important for DevOps?

DevOps engineers frequently work with Linux servers, application files, configuration files, logs, services, and permissions. Understanding where these resources are located makes server management and troubleshooting much easier.

Conclusion

The Linux directory structure may look confusing when you first start using Linux, but each major directory has a specific purpose. The most important directories to remember are /, /home, /etc, /var, /usr, /tmp, and /boot.

As you continue learning Linux, regularly explore these directories using the terminal. Understanding the filesystem hierarchy will give you a strong foundation for DevOps, Cloud Computing, System Administration, and Cyber Security.
