Linux User & Group Management

Linux is designed as a multi-user operating system. This means that multiple users can work on the same computer or server while having different levels of access.

In this guide: Learn Linux users and groups, UID and GID, whoami, id, groups, useradd, passwd, usermod, userdel, groupadd, sudo, su, important account files and practical user-management examples.

What Is a Linux User?

A user is an account that can interact with a Linux system. Linux uses user identities when determining access to files, directories, processes and other system resources.

A Linux system can have many different accounts, for example: 

anu
developer
student
admin

Each account can have different permissions and privileges.

What Is a Linux Group?

A group is a collection of users. Groups make it easier to manage permissions for several users at the same time.

For example, imagine a project has several developers: 

anu
rahul
priya
rohit

Instead of managing access separately for every user, an administrator can create a group: 

developers

The users can then be added to the group and permissions can be assigned to that group.

Tip: Groups are especially useful when several users need access to the same project files or resources.

Why Linux Uses Users and Groups

Linux systems often have multiple people, applications and services working at the same time. Users and groups provide a structured way to control access.

A simplified model is: 

User
  ↓
Group
  ↓
Permissions
  ↓
Resources

This system is closely connected to Linux file permissions.

For example: 

-rw-r-----

The permissions apply to: 

Owner  → User
Group  → Group members
Others → Everyone else

The whoami Command

The whoami command displays the username of the account running the current shell. 

whoami

Example: 

$ whoami
anu

This command is useful when working with multiple user accounts or when checking which account is currently active.

The id Command

The id command displays information about a user, including the UID, primary GID and group memberships. 

id

Example: 

uid=1000(anu) gid=1000(anu) groups=1000(anu),27(sudo)

Understanding UID

UID stands for User ID. Linux internally uses numeric IDs to identify users. 

uid=1000(anu)

Understanding GID

GID stands for Group ID. It identifies a group associated with the user. 

gid=1000(anu)

Understanding Groups

The groups section displays groups associated with the user. 

groups=1000(anu),27(sudo)

The groups Command

The groups command shows the groups associated with a user. 

groups

Example: 

anu sudo developers

You can also check another user: 

groups anu

The /etc/passwd File

The /etc/passwd file contains basic information about local user accounts.

You can inspect it using: 

cat /etc/passwd

A typical entry may look like: 

anu:x:1000:1000:Anu:/home/anu:/bin/bash

The fields are separated by colons.

Field Meaning
anu Username
x Password placeholder
1000 User ID (UID)
1000 Primary Group ID (GID)
Anu User information / GECOS field
/home/anu Home directory
/bin/bash Login shell
Important: Modern Linux systems normally keep password hashes in the protected /etc/shadow file rather than storing them directly in /etc/passwd.

The /etc/shadow File

The /etc/shadow file stores password-related information and account-aging information.

Because this information is sensitive, access to this file is normally restricted.

An administrator can inspect it with: 

sudo cat /etc/shadow
Security warning: Do not modify /etc/shadow manually unless you understand the account-management system. Use commands such as passwd for normal password management.

The /etc/group File

The /etc/group file contains information about local groups. 

cat /etc/group

An entry may look like: 

developers:x:1001:anu,rahul

It contains information such as the group name, GID and group members.

Creating a User with useradd

The useradd command can be used to create a new Linux user. 

sudo useradd username

For example: 

sudo useradd developer

For a user with a home directory and Bash as the login shell: 

sudo useradd -m -s /bin/bash developer

Here:

  • -m requests creation of the home directory.
  • -s specifies the login shell.

Setting a User Password

After creating a user, you can set its password with the passwd command. 

sudo passwd developer

Linux will ask you to enter and confirm the password. 

New password:
Retype new password:

The password is not displayed while you type it.

Managing Users with usermod

The usermod command is used to modify an existing user account.

For example, to change a user's login shell: 

sudo usermod -s /bin/bash developer

You can also modify the home directory: 

sudo usermod -d /home/newdeveloper developer

One of the most useful usermod operations is adding a user to a supplementary group. 

sudo usermod -aG developers developer

Why Is -a Important?

The -a option means append. The -G option specifies supplementary groups.

Using: 

sudo usermod -aG developers anu

adds anu to the developers group while preserving existing supplementary group memberships.

Be careful: Using usermod -G without -a can replace the user's existing supplementary group list.

Creating a Linux Group

The groupadd command creates a new group. 

sudo groupadd developers

You can verify the group with: 

getent group developers

You can also search the local group file: 

grep developers /etc/group

Managing Groups with groupmod

The groupmod command modifies an existing group.

For example, to rename a group: 

sudo groupmod -n developers-dev developers

This changes: 

developers

to: 

developers-dev

Group changes should be planned carefully on systems where applications depend on specific group names or IDs.

Deleting Users and Groups

Deleting a User

Use userdel to remove a user account: 

sudo userdel developer

To request removal of the user's home directory as well: 

sudo userdel -r developer
Warning: The -r option can permanently remove data stored in the user's home directory. Always verify the account and its data before using it.

Deleting a Group

Use groupdel to remove a group: 

sudo groupdel developers

Before deleting a group, verify that it is no longer required by users, applications or access-control configurations.

Switching Users with su

The su command means switch user.

For example: 

su developer

For a login-style shell: 

su - developer

After finishing, use: 

exit

to return to the previous shell.

Understanding sudo

sudo allows an authorized user to execute a command with elevated privileges.

For example: 

sudo useradd developer

or: 

sudo apt update

The exact commands a user can execute with sudo depend on the system's administrative configuration.

Best practice: Use elevated privileges only when they are required. Avoid running ordinary tasks as root.

Understanding the Root User

The root account is the traditional Linux superuser. It has extensive privileges and can perform system-level operations.

Root can generally:

  • Create and remove users
  • Modify system configuration
  • Change file ownership
  • Change file permissions
  • Install system software
  • Manage services

Because root has broad privileges, administrative commands should be used carefully.

Primary and Supplementary Groups

A Linux user can belong to multiple groups.

Primary Group

Every user has a primary group. You can see it with: 

id username

Example: 

uid=1000(anu) gid=1000(anu)

Supplementary Groups

A user can also belong to additional groups. 

groups=1000(anu),27(sudo),1001(developers)

Here the user has supplementary memberships in groups such as sudo and developers.

Practical Example: Create a Developer Account

Let's create a simple user and group setup.

Step 1: Create a Group

sudo groupadd developers

Step 2: Create a User

sudo useradd -m -s /bin/bash developer

Step 3: Set the Password

sudo passwd developer

Step 4: Add the User to the Group

sudo usermod -aG developers developer

Step 5: Verify the User

id developer

Step 6: Check Group Membership

groups developer

The resulting structure is conceptually: 

developers
     |
     └── developer

Common User and Group Problems

Permission Denied

You may encounter: 

Permission denied

First check the current identity: 

id

Then check group membership: 

groups

Finally inspect the relevant file or directory permissions: 

ls -l

User Is Not in the Expected Group

Check the user's groups: 

groups username

If required, an administrator can add the user: 

sudo usermod -aG groupname username

A new login session may be required before the updated supplementary group membership is reflected in the user's session.

User Does Not Have a Home Directory

Check: 

ls /home

When creating a new user, use: 

sudo useradd -m username

Linux User Management Security Best Practices

User management is an important part of Linux security.

1. Use Individual Accounts

Avoid sharing one account among multiple people when individual accounts are practical. Individual accounts make access management and auditing easier.

2. Use Groups for Shared Access

Groups are useful when multiple users need access to the same resources. 

developers
designers
database

3. Follow Least Privilege

Give users only the permissions and administrative access they actually need.

4. Use sudo Carefully

Administrative privileges should be used only when required.

5. Protect Sensitive Account Information

Files such as: 

/etc/shadow

contain sensitive account information and should not be exposed unnecessarily.

6. Review Unused Accounts

When an account is no longer required, review it and disable or remove it according to the system's account-management policy.

Frequently Asked Questions

What is a Linux user?
A Linux user is an account that identifies a person, service or process when interacting with the operating system. Linux uses the user's identity when applying access controls.
What is a Linux group?
A Linux group is a collection of users that can be managed together for access-control purposes. Groups are particularly useful when multiple users need access to the same resources.
What does whoami do in Linux?
The whoami command displays the username of the account running the current shell.
What does the id command do?
The id command displays information such as the user's UID, primary GID and group memberships.
How do I create a user in Linux?
A basic command is sudo useradd username. To request a home directory and specify Bash as the login shell, you can use sudo useradd -m -s /bin/bash username.
How do I set a Linux user's password?
Use sudo passwd username to set or change a user's password.
How do I add a user to a group?
Use sudo usermod -aG groupname username. The -a option preserves existing supplementary group memberships while adding the specified group.
What is the difference between useradd and usermod?
useradd creates a new user account, while usermod modifies an existing user account.
What is sudo in Linux?
sudo allows an authorized user to execute a command with elevated privileges according to the system's sudo configuration.
What is the root user?
Root is the traditional Linux superuser. It has extensive privileges and can perform system-level operations, so commands run with root privileges should be used carefully.
