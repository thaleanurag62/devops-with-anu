25 Essential Linux Commands Every Beginner Should Know

Introduction

Linux commands are text-based instructions that allow you to communicate directly with the Linux operating system through the terminal. Whether you want to create files, manage folders, install software, monitor processes, or configure servers, Linux commands provide a fast and efficient way to perform these tasks.

Learning Linux commands is one of the most valuable skills for anyone interested in DevOps, Cloud Computing, Cyber Security, Software Development, or System Administration. Most production servers around the world run Linux, making command-line knowledge essential for IT professionals.

Why Should You Learn Linux Commands?

Linux commands give you complete control over your operating system. Unlike graphical interfaces, the terminal allows you to work faster, automate repetitive tasks, troubleshoot problems efficiently, and manage remote servers. Companies such as Google, Amazon, Netflix, Meta, and many cloud providers rely heavily on Linux-based infrastructure, making command-line skills highly valuable in the IT industry.

  • Work faster using the terminal.
  • Manage files and folders efficiently.
  • Automate tasks using shell scripts.
  • Essential for DevOps and Cloud Computing.
  • Required in many technical interviews.

1. pwd (Print Working Directory)

Purpose: Displays the current directory you are working in.

Syntax:

pwd

Example Output:

/home/anurag/Documents

This command is useful when you want to know your current location in the Linux file system.

2. ls (List Files)

Purpose: Displays files and folders inside the current directory.

ls
ls -l
ls -a
ls -lh

The ls command is one of the most frequently used Linux commands. It helps you view files, hidden files, permissions, and file sizes.

3. cd (Change Directory)

Purpose: Move from one directory to another.

cd Documents
cd ..
cd ~
cd /etc

Use cd whenever you need to navigate through different folders in Linux.

4. mkdir (Make Directory)

Purpose: Creates a new directory.

mkdir project

You can also create multiple directories at once. 

mkdir docs images videos

5. touch

Purpose: Creates a new empty file.

touch notes.txt

This command is commonly used to create configuration files, text files, and practice files.

6. cp (Copy Files)

Purpose: Copies files or directories.

cp file1.txt backup.txt

To copy an entire directory: 

cp -r project backup

7. mv (Move or Rename)

Purpose: Moves files or renames them.

mv file.txt newfile.txt

You can also move files into another folder. 

mv notes.txt Documents/

8. rm (Remove Files)

Purpose: Deletes files and directories.

Syntax:

rm file.txt

Delete a directory and its contents:

rm -r project

Note: Be careful while using rm because deleted files cannot be easily recovered.

9. cat (Concatenate)

Purpose: Displays the contents of a file.

cat notes.txt

You can also combine multiple files using the cat command.

10. nano

Purpose: Opens the Nano text editor.

nano file.txt

Nano is a beginner-friendly text editor used for editing configuration files and scripts.

11. head

Purpose: Displays the first 10 lines of a file.

head file.txt

Show the first 20 lines:

head -20 file.txt

12. tail

Purpose: Displays the last lines of a file.

tail file.txt

Monitor a log file in real time:

tail -f /var/log/syslog

13. grep

Purpose: Searches for specific text inside a file.

grep "error" log.txt

This command is extremely useful for searching logs and configuration files.

14. find

Purpose: Finds files and folders.

find . -name "notes.txt"

You can search by file name, extension, size, and many other conditions.

15. chmod

Purpose: Changes file permissions.

chmod 755 script.sh

Example:

chmod +x install.sh

The chmod command controls who can read, write, or execute a file.

💡 Beginner Tips

  • Practice commands daily in a Linux terminal.
  • Read the manual page using man command.
  • Experiment in a virtual machine before using commands on important systems.
  • Use the history command to review what you've typed.

16. chown

Purpose: Changes the owner of a file or directory.

sudo chown username file.txt

This command is commonly used by system administrators to manage file ownership.

17. chgrp

Purpose: Changes the group ownership of a file.

sudo chgrp developers project.txt

18. ps

Purpose: Displays currently running processes.

ps
ps -ef

Useful for checking which programs are currently running.

19. top

Purpose: Displays real-time system performance and running processes.

top

Press q to exit.

20. kill

Purpose: Stops a running process.

kill 1234

Replace 1234 with the Process ID (PID).

21. df

Purpose: Shows disk space usage.

df -h

The -h option displays sizes in a human-readable format.

22. du

Purpose: Shows the size of files and directories.

du -sh Documents

23. ping

Purpose: Checks network connectivity.

ping google.com

If replies are received, your network connection is working.

24. wget

Purpose: Downloads files directly from the internet.

wget https://example.com/file.zip

25. curl

Purpose: Transfers data between a client and server.

curl https://example.com

It is widely used for testing APIs and downloading data.

Tips for Practicing Linux Commands

  • Practice commands every day for at least 20 minutes.
  • Create a virtual machine using Ubuntu or another Linux distribution.
  • Use the man command to learn more about any command.
  • Avoid running commands with sudo unless you understand their purpose.
  • Experiment by creating folders and files to build confidence.

Frequently Asked Questions

Are Linux commands case-sensitive?

Yes. Linux treats uppercase and lowercase letters as different. For example, File.txt and file.txt are different files.

Which Linux distribution is best for beginners?

Ubuntu and Linux Mint are excellent choices because they are easy to install, user-friendly, and have large communities.

Do I need to memorize all Linux commands?

No. Learn the most commonly used commands first and practice regularly. Over time, they will become familiar.

Can I use Linux commands on Windows?

Yes. You can use Windows Subsystem for Linux (WSL), a virtual machine, or Git Bash to practice Linux commands on Windows.
