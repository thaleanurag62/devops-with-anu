Introduction

Linux commands are instructions typed into the terminal to interact with the operating system. Learning Linux commands is one of the most important skills for anyone interested in DevOps, Cloud Computing, Cyber Security, System Administration or Software Development.

In this guide you will learn the most useful Linux commands with syntax, examples and explanations.

Navigation Commands (1–10)

No. Command Description Example
1 pwd Shows current working directory. pwd
2 ls Lists files and folders. ls
3 ls -l Detailed file listing. ls -l
4 ls -a Shows hidden files. ls -a
5 cd Changes directory. cd Documents
6 cd .. Go one folder back. cd ..
7 cd ~ Go to Home directory. cd ~
8 tree Displays folder structure. tree
9 clear Clears terminal screen. clear
10 history Shows previous commands. history

File Commands (11–25)

No. Command Description Example
11 touch Create a new file. touch file.txt
12 cat Display file contents. cat file.txt
13 nano Edit a file. nano file.txt
14 vim Open Vim editor. vim file.txt
15 cp Copy files. cp a.txt b.txt
16 mv Move or rename files. mv file.txt new.txt
17 rm Delete file. rm file.txt
18 rm -r Delete folder. rm -r folder
19 head Show first 10 lines. head file.txt
20 tail Show last 10 lines. tail file.txt
21 more View file page by page. more file.txt
22 less Scrollable file viewer. less file.txt
23 wc Count lines, words and characters. wc file.txt
24 sort Sort file contents. sort file.txt
25 uniq Remove duplicate lines. uniq file.txt
